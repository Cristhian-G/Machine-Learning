## 📚 Sobre este repositorio

Este repositorio reúne las tareas, prácticas, experimentos y materiales desarrollados durante la materia de **Machine Learning**. Su propósito es servir como bitácora de aprendizaje y como un espacio organizado para estudiar, implementar y comparar distintas técnicas de análisis de datos y aprendizaje automático.

Los ejercicios combinan **Python**, **R** y **Jupyter Notebooks**, utilizando conjuntos de datos conocidos como Iris, Titanic y Breast Cancer. Cada carpeta corresponde a una actividad o tema específico, con sus respectivos scripts, notebooks y datos de apoyo.

## 🚀 Uso local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Cristhian-G/Machine-Learning.git
   cd Machine-Learning
   ```

2. Para ejecutar los notebooks o scripts de Python, instala las dependencias del tema correspondiente. Por ejemplo:

   ```bash
   pip install -r Agrupamiento-jerarquico/requirements.txt
   ```

3. Abre el archivo `.ipynb` en Jupyter o ejecuta el `script.py` desde el entorno de Python.

4. Para las actividades en R, abre el archivo `.R`, `.r` o el proyecto `.Rproj` en **RStudio**.

> Las instrucciones y dependencias pueden variar entre carpetas. Consulta el contenido de cada actividad antes de ejecutarla.
